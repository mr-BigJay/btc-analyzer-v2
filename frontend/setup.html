BABTC Analyzerراه‌اندازی
خانه داشبورد پنل مدیریت نحوه استفاده راه‌اندازی سرور دامنه و SSL وضعیت سیستم مرحله بعد: SSL

راه‌اندازی روی Ubuntu ۲۴

استقرار پیشنهادی با Docker Compose: Nginx + API + Scheduler + Collectors + PostgreSQL + Redis.

پیش‌نیاز

  • سرور Ubuntu ۲۴.۰۴ با دسترسی SSH
  • حداقل ۲ vCPU، ۴GB RAM، ۴۰GB دیسک
  • پورت‌های ۲۲، ۸۰ و ۴۴۳ (برای دامنه/SSL)

۱) نصب Docker

sudo apt update
sudo apt install -y ca-certificates curl git ufw
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER
# یک‌بار خارج و دوباره وارد شوید
docker compose version

۲) فایروال

sudo ufw allow OpenSSH
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable

۳) دریافت پروژه

cd /opt
sudo git clone https://github.com/mr-BigJay/btc-analyzer-v2.git
sudo chown -R $USER:$USER btc-analyzer-v2
cd btc-analyzer-v2
git checkout cursor/persian-ui-ssl-390e

۴) تنظیم متغیرهای محیطی

cp .env.example .env
nano .env

حداقل این مقادیر را برای پروداکشن تنظیم کنید:

APP_ENV=production
API_JWT_SECRET='یک-رمز-بلند-تصادفی'
API_AUTH_ENABLED=true
API_KEYS='your-key:Administrator'
DOMAIN=example.com
LOG_LEVEL=INFO
DEBUG=0

۵) اجرای سرویس‌ها

docker compose up -d --build
docker compose ps
curl -s http://127.0.0.1/live
curl -s http://127.0.0.1/ready

پس از docker compose up وارد پنل مدیریت شوید و بقیه تنظیمات (رمز، JWT، کلید صرافی، تلگرام، دامنه) و عملیات تحلیل را از محیط گرافیکی انجام دهید.

۶) به‌روزرسانی بعدی

cd /opt/btc-analyzer-v2
git pull
docker compose up -d --build
make backup
